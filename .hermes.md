## Stack

Next.js 16 · React 19 · TypeScript · Tailwind v4 · Cloudflare (OpenNext) deploy.
Package manager: `npm`. Matches the `jadas-jazz-cafe-web` pattern.

## Required Commands

```bash
npm install      # one-time setup
npm run dev      # localhost:3009
npm run build    # production build → .open-next/
npm run start    # serve production build
npm run lint     # ESLint (no jest/vitest in baseline)
```

## Source-of-truth rules for THIS project

When sources disagree inside this folder:
1. **Code wins over docs**: if `src/` and `*.md` disagree, the code is the
   truth-source and the doc needs updating.
2. **`AGENTS.md` wins over README.md** for project conventions.
3. **`research/intake/` is historical** — it drove stage-1 decisions; do not
   re-litigate them in Stage 4+ without an explicit reason.
4. **`.hermes/plans/` is read-only history** — append-only. Update by writing
   a new plan, never editing an old one.
