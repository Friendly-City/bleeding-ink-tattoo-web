| File | Purpose | Stage |

| `01-competitor-sites.md` | Scraped data from Bleeding Ink's existing web presence + comparable local shops | Stage 1.5 |

- Reference images for the brand direction live in `02-design-inspiration.md` (linked, not downloaded, to avoid copyright issues).
- All scraping happens against the local Firecrawl (`http://localhost:3002`) — no public API calls.
